# Stirring Up

Website for Stirring Up, a mobile mixologist service for weddings, private celebrations, and corporate gatherings in Dallas Fort Worth.

The site is a single self contained page in index.html. It is hosted on Netlify (project sunny-melba-466240, custom domain stirringup.live) and deployed manually by uploading index.html on the project's Deploys page. Pushing to this repository does not publish the site on its own.
